
¿Qué Problema Resuelve?

El proyecto CoAgrix busca resolver la dificultad que tienen muchos <campesinos para dar a conocer y comercializar sus productos de manera directa con empresas y comerciantes.

Actualmente, muchos agricultores no cuentan con una plataforma donde puedan publicar fácilmente sus productos y establecer contacto con posibles compradores. Esto limita las oportunidades de negocio y dificulta la comunicación entre productores y empresas interesadas.

La aplicación permitirá que los campesinos publiquen información sobre sus productos agrícolas, mientras que las empresas y comerciantes podrán contactarlos y agendar citas o reuniones directamente desde la plataforma. De esta manera, se busca facilitar la conexión entre vendedores y compradores sin intervenir en la gestión interna de los cultivos o negocios de cada productor.

Decisiones Iniciales
Metodología de Desarrollo
Elegí: Metodología Ágil (Scrum)
¿Por qué?
Se eligió una metodología ágil porque permite desarrollar el proyecto por etapas, realizar mejoras continuas y adaptarse fácilmente a nuevos requerimientos. Además, facilita la organización del trabajo en equipo y permite entregar avances funcionales constantemente.
________________________________________
Arquitectura Inicial
Elegí: Arquitectura MVC (Modelo - Vista - Controlador)
¿Por qué?
Se eligió la arquitectura MVC porque permite organizar mejor el proyecto separando:
●	La lógica del sistema.
●	La interfaz visual.
●	El manejo de datos.
Esto facilita el mantenimiento, la escalabilidad y el trabajo colaborativo, además de ser una arquitectura muy utilizada en aplicaciones web modernas.
